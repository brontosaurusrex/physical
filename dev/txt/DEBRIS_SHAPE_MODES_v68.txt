DEBRIS SHAPE MODES — v68
========================

The debris generator now has one string mode that can be selected globally in
config.go or overridden by an individual level.

CONFIG.GO DEFAULT

  defaultDebrisShapeMode = "mixed"

Accepted values:

  mixed       existing varied debris: circles, triangles, stars, glass,
              slivers, compact chunks, and rounded brick-like chunks

  triangles   every newly created fragment is a sharp three-edge triangle;
              no circles, stars, glass polygons, rounded chunks, or slivers

  circles     every newly created fragment is a circular chip

LEVEL OVERRIDE

  debrisShapeMode=mixed
  debrisShapeMode=triangles
  debrisShapeMode=circles

The parser is case-insensitive and also accepts the singular aliases triangle
and circle. Diagnostics display the canonical MIXED, TRIANGLES, or CIRCLES name.

PERFORMANCE TESTING

Use Shift+F immediately before a comparable debris-heavy run to reset LOWEST
FPS. Keep the same level, window size, browser, shard count, and test duration.
Compare mixed, triangles, and circles one at a time.

Triangles are deliberately unrounded in forced triangle mode, so each cached
Path2D consists of exactly three straight edges. Circles use one arc and remain
distinct as a separate test even though they visually resemble the ball.

The mode changes shape generation only. It does not change:

  debrisPiecesMin       6
  debrisPiecesMax       18
  debrisMaxActivePieces 150
  physics, collision, lifetime, launch speed, adaptive rendering, or depth order

Only newly created fragments use the selected mode. Existing fragments retain
the shape with which they were created. Loading/restarting a level clears the
old debris naturally.

In triangles or circles mode, the individual mixed-shape chance settings remain
stored but are ignored until debrisShapeMode returns to mixed.
