PER-LEVEL PHYSICS SETTINGS
==========================

Put overrides before the --- separator in a level file. Omitted values use the
matching defaults from config.go. Names are case-sensitive.

  maxSpin=1530                     # > 0
  stuckSpeedThreshold=85           # >= 0
  stuckDuration=1.2                # >= 0
  tiltUpSpeed=520                  # >= 0
  tiltSideMin=180                  # >= 0
  tiltSideMax=340                  # >= 0

BALL RESCUE / TELEPORT
----------------------
These settings govern the automatic fallback after TILT! and Orbital tilt!:

  ballRescue=true
  ballRescueFailureLimit=4
  ballRescueMinProgress=80
  ballRescueCheckDuration=1.0
  ballRescueUpperScreenFraction=0.333333
  ballRescueClearance=12
  ballRescueLaunchSpeed=520
  ballRescueMinRealtimePercent=90
  ballRescueMaxComputeLoad=85

A normal TILT! measures total displacement. Orbital tilt measures only the orbit
minor axis: horizontal movement for a vertical orbit and vertical movement for a
horizontal orbit. Successful progress resets the consecutive-failure count.

A failed attempt counts only when the fixed-step simulation is healthy: realtime
percentage meets the minimum, compute load stays below the maximum, and no recent
physics warning/dropped-time event is active. On the configured failure limit,
the ball is placed in a collision-free position, preferring the upper third.

Press T during active gameplay for a manual teleport. It uses the same safe
position and launch logic but intentionally bypasses the performance gate.
