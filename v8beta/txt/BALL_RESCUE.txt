BALL RESCUE — v57

AUTOMATIC FALLBACK

Every normal TILT! starts a progress check using total ball displacement. Every
Orbital tilt! starts a minor-axis check so movement around the same orbit does not
look like an escape. The default check is 80 pixels within 1.0 second.

Four consecutive failed attempts trigger a safe teleport. A successful attempt
resets the count. Failed attempts observed while the simulation is slow,
throttled, dropping time, or using too much compute are discarded rather than
counted.

SAFE POSITION

The search prefers collision-free positions in the upper third. It avoids living
bricks, the paddle, the other active ball, canvas edges, and the black-hole core.
If no opening exists in the upper third, it expands downward but stays above the
paddle. The relocated ball receives a 520 px/s downward-biased launch by default.

MANUAL CHEAT

Press T during active gameplay to teleport the primary ball immediately. This
uses the same safe search and launch behavior, resets the failure counter, and
intentionally bypasses the performance gate.

DEFAULT SETTINGS

  ballRescue=true
  ballRescueFailureLimit=4
  ballRescueMinProgress=80
  ballRescueCheckDuration=1.0
  ballRescueUpperScreenFraction=0.333333
  ballRescueClearance=12
  ballRescueLaunchSpeed=520
  ballRescueMinRealtimePercent=90
  ballRescueMaxComputeLoad=85

DIAGNOSTICS

Press P. RESCUE PERF GATE reports OK or BLOCKED, and RESCUE FAILURES B1/B2 shows
the current consecutive healthy failure count.
